# Issue tracker: GitHub

Issues live as GitHub issues on `vextrus/vextrus`, driven with the `gh` CLI. The full
conventions — everyday operations, wayfinding operations (map, sub-issues, native blocking,
claim by assignee, the frontier query) and labels — are in **`docs/tracker.md`**. Read that.

**PRs as a request surface: no.**

When a skill says "publish to the issue tracker": create a GitHub issue. When a skill says
"fetch the relevant ticket": `gh issue view <number> --comments`.
