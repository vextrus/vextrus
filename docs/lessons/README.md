# Lessons — the instrument lies before the build does

One fault per file, named for the fault, a one-line summary at the top. An entry is added only
with a dated, observed cost — never speculatively. Read this directory when something is broken
and the code looks right. Corrections and confirmed approaches alike; update rather than
duplicate; delete what turns out wrong. (One file per lesson because an append-only shared file
is a merge conflict waiting for its second author.)
